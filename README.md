# מפת מורשת ישראל (Israel Heritage Map)

מפה אינטראקטיבית של ישראל, בחלוקה לשכבות, המיועדת לשימוש מקצועי על ידי מורי דרך:

- **שכבת אזורים** — חלוקת הארץ לאזורים גיאוגרפיים מוכרים (גליל, גולן, שומרון, נגב וכו').
- **שכבת גיאולוגיה** — 8 יחידות גיאולוגיות בתצוגה בסיסית + 19 בתצוגה מעמיקה (סוג סלע, גיל, ומה חשוב להסביר למטיילים), עם מתג בסיסי/מעמיק.
- **ציר זמן היסטורי** — סליידר לבחירת תקופה (מהתקופה הפרהיסטורית ועד ימינו), עם סימון אתרים מרכזיים לכל תקופה. אתרי "בית ראשון" ו"בית שני" מסומנים גם כתגית חוצת-תקופות.
- **שכבת אתרי דת** — אתרים מרכזיים ליהדות, לנצרות ולאסלאם.
- שכבות ניתנות להצגה **חופפת** (למשל: אתרים היסטוריים + אתרי דת יחד).
- **בניית מסלול סיור** — הוספת אתרים לרשימת מסלול אישית, נשמרת מקומית (localStorage) גם ללא אינטרנט.
- **"מה יש כאן?"** — איתור מיקום נוכחי והצגת אתרים מתועדים בסביבה.
- **תמיכה אופליין (PWA)** — Service Worker שומר את מעטפת האפליקציה ואת האריחים (tiles) שנצפו, ויש כפתור לשמירה יזומה של האזור הנוכחי לשימוש בשטח ללא קליטה.

## הרצה מקומית

אין תהליך build — קבצי HTML/CSS/JS סטטיים בלבד.

```bash
python3 -m http.server 8000
# ואז פתח http://localhost:8000
```

לשימוש כאפליקציה מותקנת (PWA), יש להגיש את הקבצים over HTTPS (או localhost) כדי שה-Service Worker יירשם.

## מבנה הפרויקט

```
israel-heritage-map/
├── index.html          # מעטפת האפליקציה
├── css/style.css        # עיצוב (RTL, פלטת "ים תיכוני" בהירה וטרייה, Rubik)
├── js/app.js             # הלוגיקה: מפה, שכבות, סינון, מסלול, אופליין
├── js/data/
│   ├── periods.json          # הגדרת 18 התקופות ההיסטוריות
│   ├── regions.geojson       # פוליגוני אזורים (גרסה ראשונית מקורבת)
│   ├── geology_basic.geojson    # 8 יחידות גיאולוגיות (תצוגה בסיסית)
│   ├── geology_advanced.geojson # 19 יחידות גיאולוגיות (תצוגה מעמיקה)
│   ├── religions.json        # הגדרת 3 הדתות
│   └── sites.geojson         # מאגר האתרים (תקופות + דתות + מקורות)
├── icons/svg/            # סט אייקונים שרטוטי-יד (תקופות, שכבות, לוגו)
├── vendor/leaflet/       # ספריית Leaflet ממוקמת מקומית (לשימוש אופליין)
├── vendor/fonts/rubik/   # גופן Rubik ממוקם מקומית (עברית + לטינית, לשימוש אופליין)
├── manifest.webmanifest  # מניפסט PWA
└── sw.js                 # Service Worker (קאשינג אופליין)
```

## מקורות מידע

כל אתר במאגר הנתונים כולל שדה `sources` עם קישורים למקורות (בעיקר ויקיפדיה, רשות הטבע והגנים, רשות העתיקות ואתרי מוזיאונים/מחקר). זהו דרישה קבועה בפרויקט — **אין להוסיף אתר בלי מקור מאומת**.

## מגבלות ידועות בגרסה זו (v1)

- **גבולות האזורים/גיאולוגיה** (`regions.geojson`, `geology_*.geojson`) הם תיבות גיאוגרפיות מקורבות לצורך ויזואליזציה ראשונית — יש להחליף בעתיד בשכבת GIS מדויקת (למשל מהמכון הגיאולוגי לישראל).
- **שכבות נוספות שתוכננו ועדיין לא נבנו**: מפה טופוגרפית, מפה תנ"כית.
- **קאשינג אריחים אופליין** משתמש בשרת האריחים הציבורי של OpenStreetMap. יש להימנע משימוש כבד/אוטומטי בהיקף גדול (מדיניות שימוש הוגן של OSM) — לקראת מסחור המוצר כדאי לעבור לספק ייעודי (למשל MapTiler) עם רישיון offline מסחרי.
